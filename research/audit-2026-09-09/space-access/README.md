# Space access and bounded subject choices — RADD-1115

The space access panel searches and pages grants in 50-row windows. SQL filters by authorized names before count/paging; names hydrate only for the returned window. Wiki-only readers can inspect readable spaces without unrelated issue-project access. Role/team/group catalog gates still apply, including credential narrowing. Hidden labels do not leak through search totals. Rows distinguish people, teams and directory groups and retain expired grants and inactive-account labels.

A separate grant dialog loads lean person/team/group/role choices on demand, preserving UUID values and the selected space scope. Public person choices exclude email requesters and private email fields while retaining inactive/service account names. Existing automation email/name-valued endpoints remain compatible. Individual grant/revoke writes preserve unseen rows; read/write failures remain visible, and last-page deletion recovers the preceding window. Error alerts were added after the real browser exposed an inaccessible revoke-failure state.
